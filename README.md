# learn-embedded-c
C programming and bit manipulation exercises for embedded systems

組み込み・IoTエンジニアを目指すためのC言語およびマイクロコントローラ（ESP32）の学習リポジトリです。

## 📁 含まれているプロジェクト (project content)

1. **main.c**
   - Windows環境（MSYS2/GCC）でのC言語環境構築のテストプログラム。
2. **bitwise.c**
   - 組み込み開発に必須となる**ビット操作（Bitwise Operation）**の完全独学プログラム。
   - OR (`|`) によるビットON（LED点灯シミュレーション）
   - AND & NOT (`& ~`) によるビットOFF（LED消灯シミュレーション）
   - XOR (`^`) によるビット反転（LED点滅・トグル処理）

## 🛠️ 開発環境 (Development Environment)
- **OS:** Windows 11 / 10
- **Compiler:** GCC (MSYS2 MinGW-w64)
- **Editor:** Visual Studio Code
- **Simulator:** Wokwi (ESP32 / MQTT Connection)
